# @builtbyfield/maplibre-expression-helpers

A collection of wrapper functions for working with MapLibre Style Specification expressions in TypeScript.

## Features

- Type-safe wrapper functions for MapLibre expressions

## Installation

```bash
# npm
npm install @builtbyfield/maplibre-expression-helpers

# yarn
yarn add @builtbyfield/maplibre-expression-helpers

# pnpm
pnpm add @builtbyfield/maplibre-expression-helpers
```
